# Contributing

Thanks for your interest in contributing!

## Branches
- `main` is the development branch.
- `public` is generated from `main` using `./scripts/export-public.sh`.

## Setup
```bash
npm install
npm start
npm run android
```

## Tests
```bash
npm test
npm run lint
```

## Pull Requests
- Keep PRs focused and scoped.
- Include a clear description and testing notes.
- Add screenshots or screen recordings for UI changes.

## Code Style
- TypeScript only for app code.
- Named exports only.
- Single quotes and explicit semicolons.

## UI Changes
See `UI_MANUAL.md` for asset and theme locations.
