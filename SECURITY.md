# Security Policy

## Supported Versions
We support the latest commit on the `main` branch and the latest `public` export.

## Reporting a Vulnerability
Please report security issues via GitHub Security Advisories:
1. Go to the repository on GitHub.
2. Click **Security** → **Advisories** → **New draft security advisory**.

If you cannot use GitHub Security Advisories, open a private communication channel with the maintainers.

We aim to acknowledge reports within 72 hours and provide a remediation plan or timeline as soon as possible.
