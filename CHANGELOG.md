# Changelog

All notable changes to Melech HaMamad are documented here.

## [4.0] — March 2026

- Removed Cat character from the roster
- Fixed character parade display on the landing page
- Normalized character PNG assets
- Updated website favicon
- Bumped Android build version to 4.0

## [3.0] — March 2026

- Landing page redesign with animated character parade
- Added install instructions and GitHub links to landing page
- Character card and station UI polish

## [2.0] — March 2026

- Added **Charging Station** — drag the plug onto a moving phone
- Added **Reception Hunter** — slide to the sweet spot and hold for 1 second
- All 5 stations now playable
- Finalized Leaderboard and Tutorial screens with full ranking logic

## [1.0] — March 2026

- Initial release
- Core game loop: 4 characters, 3 stations (Water, Snacks, Dog Ball)
- Pause system, lives, score, and combo tracking
- Difficulty scaling: spawn rate and timers tighten every 1,000 points
- MMKV-based persistent leaderboard
- Responsive UI scaling system
